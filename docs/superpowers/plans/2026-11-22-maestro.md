# MAESTRO Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Site gratuit MAESTRO : test sur 4 piliers, programme foot 12 semaines, fiches d'exercices, suivi de progression, sans compte, avec une DA "labo de performance".

**Architecture:** Next.js App Router entièrement statique (SSG). Le contenu (questions, profils, exercices, programme) vit dans `src/content/*.ts`. L'état utilisateur (réponses, séances faites, mesures) vit dans `localStorage` via un seul module. Supabase reçoit uniquement des événements anonymes.

**Tech Stack:** Next.js 15 (App Router, TypeScript), Tailwind v4 (`@tailwindcss/postcss`), `motion` (import `motion/react`), `@phosphor-icons/react`, `next/font/google` (Archivo, JetBrains Mono), `@supabase/supabase-js`, Vitest pour les tests de logique.

**Spec:** `docs/superpowers/specs/2026-11-22-maestro-design.md`

## Global Constraints

- Aucune donnée personnelle collectée. Aucun cookie, aucun traceur tiers. Pas de compte.
- Pas de Coach IA, pas d'appel IA, pas de pub, pas de Stripe.
- Textes en français, tutoiement pour le joueur, vouvoiement dans le bloc parents.
- Zéro emoji. Zéro tiret cadratin (`—`) ou demi-cadratin (`–`) visible. Icônes Phosphor uniquement, `weight="regular"`.
- Couleurs en variables CSS dans `src/app/globals.css` : `--bg #EEF0EE`, `--ink #111413`, `--ink-2 #4A504D`, `--surface-dark #1A1D1C`, `--line #CDD2CF`, `--signal #C8F03C` (fluo, uniquement sur `--surface-dark`), `--blue #2F5BD3` (touche ponctuelle, graphiques uniquement). Valeurs exactes ajustables par le builder, rôles non.
- Typo : Archivo (axe `wdth`, titres condensés 75-85 %), JetBrains Mono pour chiffres et données. Pas d'Inter, pas de serif.
- Rayon : 2px partout (`--radius: 2px`), boutons inclus.
- Animations : `transform`/`opacity` uniquement, toutes coupées sous `prefers-reduced-motion: reduce`. Pas de `window.addEventListener('scroll')`.
- Exercices au poids du corps, volumes adaptés 13-14 ans. Avertissement "relecture par un éducateur sportif recommandée" sur `/programme` et chaque fiche.

2. Test quitté au milieu puis rouvert : reprend à la question en cours, et "Recommencer" efface tout. Test dans Task 3.
3. URL invalide (`/programme/semaine/13`, `/exercices/inconnu`) : vraie page 404 du site, pas de crash. Test dans Task 4 (`isValidWeek`) + `notFound()` dans Task 6/5.

5. Supabase injoignable ou variables d'env absentes : `track()` ne lance jamais d'erreur, l'UI ne change pas. Test dans Task 9.

**Interfaces:**

  - `QUESTIONS: { id: string; pillar: Pillar; text: string; reversed: boolean }[]` : 12 questions, 3 par pilier, échelle 1 (jamais) à 5 (tout le temps). `reversed: true` quand "souvent" est mauvais (ex. "Avant un match important, je stresse beaucoup").
  - `PROFILES: Record<ProfileId, { name: string; summary: string; strength: string; focus: string }>`, `type ProfileId = 'maestro' | 'technique' | 'physique' | 'mental' | 'vision'`. Les 4 derniers nomment le pilier à travailler en premier.

  - Clé de stockage `quiz` : `{ answers: Record<string, number>; current: number }`.

  - `QUESTIONS.length === 12`, 3 par pilier, ids uniques
  - `scoreQuiz` lance si une réponse manque
